\# CivicOps — Civic Infrastructure \& Smart Maintenance Management Platform



CivicOps is a full-stack civic infrastructure management platform that connects citizens, government departments, contractors, and field workers to manage public infrastructure complaints and maintenance workflows.



\## Problem Statement



Civic infrastructure issues such as damaged roads, broken streetlights, and water leaks need a transparent process for reporting, assigning, repairing, and verifying work.



CivicOps aims to bring these activities into one connected platform.



\## Core Features



\- Role-based authentication and authorization

\- Infrastructure complaint reporting and tracking

\- Department and contractor management

\- Maintenance work-order creation and assignment

\- Repair progress tracking and evidence submission

\- Repair verification and complaint closure

\- SLA monitoring and audit history

\- Asynchronous notifications

\- Role-specific dashboards



\## Technology Stack



\- \*\*Frontend:\*\* React, JavaScript, Vite

\- \*\*Backend:\*\* Java 17, Spring Boot

\- \*\*Microservices:\*\* Spring Cloud, Eureka, API Gateway

\- \*\*Security:\*\* Spring Security, JWT

\- \*\*Database:\*\* MySQL

\- \*\*Messaging:\*\* Apache Kafka

\- \*\*Testing:\*\* JUnit 5, Mockito

\- \*\*Build:\*\* Maven, npm

\- \*\*Deployment:\*\* Docker, Docker Compose, AWS

\- \*\*CI/CD:\*\* GitHub Actions



\## Repository Structure



\- `frontend/` — React application

\- `docs/` — Requirements, architecture, and API documentation
